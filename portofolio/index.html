01 About

Software that stays boring in production.

I started writing production code at Solace Software in 2021 and haven't stopped. Most of my work lives in the unglamorous core of an organisation — admissions, enrollment, transcripts, attendance, payroll, tax — where a wrong number is a real problem for a real person.

That shapes how I build: types that model the domain precisely, failures handled as values instead of surprises, and environments anyone can reproduce with one command. I work across the whole stack — schema, API, UI and the server it ships to — and I'm happiest when a refactor makes an entire class of bug impossible.

  1. 01

    Types are the spec

    Parse input at the edges with valibot or zod, brand what must be trusted, and make illegal states unrepresentable.

  2. 02

    Errors are values

    Expected failures are typed results — Effect, true-myth, fp-ts — that the caller must handle. Nothing is swallowed.

  3. 03

    Reproducible by default

    Every project ships a Nix flake dev shell and a Docker setup, so "works on my machine" means it works on yours.

  4. 04

    Compose, don't configure

    Small functions that each do one step, with policy chosen by the caller. No boolean flags, no god functions.

School Management System → Sola

A complete student information system for a higher-education institution, from admission to graduation. I've worked on it since 2021, and in 2026 I led its rebuild as Sola, a type-safe monorepo that replaces the legacy stack.

  • Admissions engine: configurable application processes, form sections, referral forms and admission requirements.
  • Academics: programs, concentrations, courses with prerequisites, course offerings, grading and official PDF transcripts.
  • Finance: student expenses, scholarships and payments, with exports to PDF, CSV and DOCX.
  • Access control with global roles plus permissions scoped to a single course offering.
  • Sola: tRPC over a 79-model Prisma schema, Effect on the server, better-auth, S3 storage, Postgres trigram search and a full Arabic interface with RTL layout.
  • Folded a separate forms service into one database and shipped it all with Docker on a VPS.
