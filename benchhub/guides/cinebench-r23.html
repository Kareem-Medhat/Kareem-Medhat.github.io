What it tests and when to use it

Cinebench R23 renders a 3D image using only your processor (CPU). It shows whether your CPU is as fast as it should be. Use it after building a PC, after changing your cooler, or when the PC feels slower than it used to.

The multi-core test uses all CPU cores together. The single-core test uses one core. Both scores are in points (pts). Higher is better.

Before you start

  1. Save your work. Close other apps, including browsers, game launchers and chat apps. They use processing power and lower your score.
  2. On a laptop, plug in the charger. On battery, most laptops slow down to save power.
  3. Install a temperature monitor. We use HWiNFO (free). It shows how hot your CPU and GPU get during the test.
  4. On Windows 11, set the fastest power mode: Settings → System → Power & battery → Power mode → Best performance.
  5. Restart the PC, then leave it idle for 5 minutes. Windows often runs updates and background tasks right after startup.

Download

Download Cinebench only from Maxon's official Cinebench page. Maxon makes Cinebench and offers it for free. Other download sites can bundle unwanted software.

Install and set up

  1. Open Maxon's Cinebench page.
  2. Find Cinebench R23. It's an older version, so Maxon may list it separately from the current release.
  3. Download the version for your operating system and unpack or install it.
  4. Start Cinebench R23.

Run the test

Use Cinebench R23. Scores from other Cinebench versions use a different scale and can't be compared.

  1. Leave every setting at its default. By default, R23 repeats the test for several minutes before it shows a final score.
  2. Next to CPU (Multi Core), select Start.
  3. Don't use the PC while the test runs.
  4. Wait until the final score appears.
  5. Optional: run CPU (Single Core) the same way. Run one test at a time.

Read your result

Your score appears in points (pts) next to the test you ran. Higher is better. Write down the exact number.

R23 scores are on a different scale from Cinebench 2024 and 2026. Never compare them with each other.

Troubleshooting

My score is low

  1. Go through Before you start again. Background apps and a battery-saving power mode are the most common causes.
  2. Run the test again with HWiNFO open. If the temperature climbs to its limit and the clock speed drops, that's thermal throttling (see below).
  3. Check your memory (RAM) speed in HWiNFO. If it's lower than the speed printed on your RAM, turn on the memory profile in your BIOS. It's called XMP on Intel systems and EXPO on AMD systems.
  4. Run the test two or three times. Small differences between runs (a few percent) are normal.

It crashes, freezes or the PC restarts

  1. Undo any overclock or undervolt. The simplest way is to load the default settings in your BIOS. (The BIOS is the setup screen your PC shows before Windows starts.)
  2. Update your graphics driver from your GPU maker's website (NVIDIA, AMD or Intel).
  3. Check temperatures. Overheating can cause sudden shutdowns.

Thermal throttling

Thermal throttling means your processor or graphics card slows itself down because it's too hot. It protects the hardware, but it lowers your score.

  1. Clean out dust from fans, filters and heatsinks. (A heatsink is the metal block with fins that pulls heat away from the chip.)
  2. Check that every fan spins while the test runs.
  3. Give the case room to breathe: don't push it against a wall or put it in a closed cabinet.
  4. On a laptop, use it on a hard, flat surface, not a bed or a couch.
  5. If temperatures are still high, the cooler may not be mounted properly. Ask someone experienced or a repair shop to check it.
