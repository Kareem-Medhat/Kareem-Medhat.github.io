Guides

Step-by-step instructions for each tool: where to download it safely, which test to run, and which number to check.

Which test should I run?

Find your question, run the test next to it, then type your result into the checker. Each tool's points are on its own scale, so only compare a score with reference scores from the same test.

I want to know…Run thisWhat it tells you
Is my processor (CPU) as fast as it should be for heavy work, like rendering or exporting video?Cinebench 2026One long, heavy job that uses every core. A low score usually points to heat or a power limit holding the CPU back.
What if the checker has no Cinebench 2026 scores for my CPU?Cinebench R23The same kind of test in an older version. It has been around longer, so more CPUs have reference scores, especially older ones.
Is my PC as quick as it should be in everyday use, like browsing and office apps?Geekbench 6Short, everyday-style tasks, done in a few minutes. The single-core score is the one that matches how snappy the PC feels.
Is my graphics card (GPU) as fast as it should be in games?3DMark Steel NomadA heavy, modern graphics test. Its score depends almost only on the graphics card, so it is the cleanest way to check one.
What if there are no Steel Nomad scores for my graphics card, or it is too slow to run it?3DMark Time SpyAn older, lighter graphics test that most cards can run. Use the graphics score, not the overall score.
Is my graphics card overheating? (games crash, the PC shuts off, the fans get very loud)FurMark 2A stress test, not a speed score. You compare the highest temperature you saw with your card's maximum. Read its safety warning first.

Not sure which one applies? Pick your hardware in the checker first. It only lists the tests we have trusted reference scores for.
