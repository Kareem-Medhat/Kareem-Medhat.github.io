Which test should I run?

I want to know…Run thisWhy this one
Is my processor (CPU) as fast as it should be?Cinebench 2026The most common CPU test. One long, heavy job that also shows if your CPU gets too hot.
I just want a quick CPU checkGeekbench 6Done in a few minutes. Runs short, everyday-style tasks.
Is my graphics card (GPU) as fast as it should be?3DMark Time SpyThe most widely used graphics card test.
I have a powerful, recent graphics card3DMark Steel NomadNewer and heavier than Time Spy, so it still challenges fast cards.
Is my graphics card stable and cool? (games crash, PC shuts off, it runs very hot)FurMark 2A stress test: a health check, not a speed score. Read its safety warning first.
I already have a Cinebench R23 scoreCinebench R23R23 uses its own scale, so it needs R23 reference scores.
